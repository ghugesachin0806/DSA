Max and Min of Two Values : 

int max = Math.max(10, 20); // 20
int min = Math.min(10, 20); // 10

double maxD = Math.max(5.5, 3.2); // 5.5
double minD = Math.min(5.5, 3.2); // 3.2

Supported types: int, long, float, double.
---------------------------------------------------------------------------------------------------------------
max and min values in Java for int and long types:

int min = Integer.MIN_VALUE; // -2147483648
int max = Integer.MAX_VALUE; // 2147483647

long min = Long.MIN_VALUE;   // -9223372036854775808L
long max = Long.MAX_VALUE;   // 9223372036854775807L
