1. Basic Operations

List<Integer> numbers = new ArrayList<>();

// 1. add(E e) - Adds an element
numbers.add(10);
numbers.add(20);
System.out.println(numbers); // [10, 20]

// 2. addAll(Collection<? extends E> c) - Adds all from another collection
List<Integer> moreNumbers = new ArrayList<>();
moreNumbers.add(30);
moreNumbers.add(40);
numbers.addAll(moreNumbers);
System.out.println(numbers); // [10, 20, 30, 40]

// 3. remove(Object o) - Removes first occurrence of 20
numbers.remove(2);         // Remove element at index 2
numbers.remove(Integer.valueOf(20)); // Remove value 20
System.out.println(numbers); // [10, 30, 40]

// 4. clear() - Removes all elements
numbers.clear();
System.out.println(numbers); // []

// 5. size() - Returns number of elements
numbers.add(50);
System.out.println(numbers.size()); // 1

// 6. isEmpty() - Checks if collection is empty
System.out.println(numbers.isEmpty()); // false

// 7. contains(Object o) - Checks if element exists
System.out.println(numbers.contains(50)); // true

// Removing Elements While Iterating (Safe)

List<Integer> list = new ArrayList<>(Arrays.asList(10, 15, 20, 25, 30));
Iterator<Integer> it = list.iterator();

while (it.hasNext()) {
    Integer val = it.next();
    if (val % 10 == 0) {
        it.remove();  // Safe removal
    }
}
System.out.println(list); // [15, 25]

    System.out.println(num);

4. ListIterator

* ListIterator is a bidirectional iterator that allows:
    - Forward and backward traversal of a List
    - Modifying, adding, or removing elements during iteration

List<Integer> list = new ArrayList<>(Arrays.asList(10, 20, 30));
ListIterator<Integer> it = list.listIterator();

+++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++
public class Main {
    public static void main(String[] args) {
        List<Integer> list = new ArrayList<>(Arrays.asList(10, 20, 30, 40));
        ListIterator<Integer> it = list.listIterator();

        System.out.println("Forward (with removal):");
        while (it.hasNext()) {
            int val = it.next();
            System.out.println("Visited: " + val);

            if (val == 20 || val == 40) {
                it.remove(); // safely remove 20 and 40
                System.out.println("Removed: " + val);
            }
        }

        System.out.println("\nList after forward pass: " + list);

        System.out.println("\nBackward traversal:");
        while (it.hasPrevious()) {
            System.out.println("Visited: " + it.previous());
        }

        System.out.println("\nFinal List: " + list);
    }
}

Output : 

Forward (with removal):
Visited: 10
Visited: 20
Removed: 20
Visited: 30
Visited: 40
Removed: 40

List after forward pass: [10, 30]

Backward traversal:
Visited: 30
Visited: 10

Final List: [10, 30]

9. List to subList

- startIndex is inclusive.
- endIndex is exclusive.

List<Integer> firstList = list.subList(start, mid + 1);
List<Integer> secondList = list.subList(mid + 1, end + 1);
--->
- List.subList() returns a view of the original list.
- When you do list.set(...) to overwrite the original list during merging, you may inadvertently affect firstList
  and secondList, corrupting the input mid-merge.

Make copies of the sublists so you don’t accidentally modify the same data you're reading from.
List<Integer> firstList = new ArrayList<>(list.subList(start, mid + 1));
List<Integer> secondList = new ArrayList<>(list.subList(mid + 1, end + 1));

11. Creating a 2D ArrayList in Java

ArrayList<ArrayList<String>> matrix = new ArrayList<>();

int rows = 3, cols = 3;
List<List<Integer>> matrix = new ArrayList<>();

for (int i = 0; i < rows; i++) {
    List<Integer> row = new ArrayList<>();
    for (int j = 0; j < cols; j++) {
        row.add(i + j);  // example value
    }
    matrix.add(row);
}

// Print matrix
for (List<Integer> row : matrix) {
    System.out.println(row);
}

Output:

[0, 1, 2]
[1, 2, 3]
[2, 3, 4]

11.1 Shortcut with Collections.nCopies(...)

int rows = 3, cols = 4;
int defaultValue = 0;

List<List<Integer>> matrix = new ArrayList<>();

    matrix.add(new ArrayList<>(Collections.nCopies(cols, defaultValue)));

6. binarySearch(List<? extends Comparable>, key)

int index = Collections.binarySearch(list, key);

Returns:
    - Index ≥ 0: if the key is found.
    - Negative value: -(insertion point) - 1 if the key is not found.

* The list must be sorted before calling binarySearch(), otherwise the result is undefined.
* Use Collections.sort(list) before searching.

List<Integer> list = Arrays.asList(30, 10, 20);
Collections.sort(list);
int index = Collections.binarySearch(list, 20);  // index of 20
